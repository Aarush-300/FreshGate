# Walk through a changing claim

Use a short answer that a reader could realistically publish. FreshGate's built-in example combines a Python release, company leadership and model pricing. Those facts can change independently, which makes the example useful for showing why a paragraph needs more than one verdict.

## Before starting

Start the server, register a local account and save working provider and Tavily settings in Profile. For a repeatable presentation, prepare one previously verified claim with two saved snapshots. Live retrieval takes time, and two consecutive searches may find the same sources. Keep any earlier result labeled with its actual check time.

## The walkthrough

1. **Show the input.** In Verify, choose **Try an example** and read one time-sensitive statement aloud. Ask which source a reader would consult before relying on it.
2. **Run the check.** Open the relevant claim and follow one citation. Read the score together with the verdict, source date and explanation. An unverifiable result is a valid demonstration of insufficient evidence.
3. **Change the evidence rule.** In Policy Studio preview a version policy requiring two independent sources. Supply a sample with one source and inspect the requirement outcome. A preview uses supplied evidence and needs no live search.
4. **Follow the claim over time.** Enroll it in Watchtower. Show its baseline, next check time and **Check now** control. Open the prepared claim in Replay, select two snapshots, and inspect the source or score difference. If neither changed, report the stable result.
5. **Show the developer path.** With a configured native Bifrost host, send the non-streaming request in the plugin guide. Point to the provider's completion beside the per-claim report and freshness headers. For a proxy demonstration, identify it as the HTTP proxy so the audience knows which integration produced the result. [Bifrost guide](bifrost-notes.md)

A useful closing artifact is the Replay HTML report or a CSV record. It gives the reader a claim, its evidence and a check time to revisit after the walkthrough.
